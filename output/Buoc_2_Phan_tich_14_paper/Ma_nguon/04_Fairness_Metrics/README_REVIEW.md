# Ghi chú README, tự biên soạn

README nhận diện đây là bản mở rộng công trình SIGIR2024. Thông tin tải datasets và training ban đầu nằm ở repo tiền thân. Các metrics liên quan relevance và exposure-only cần trích dẫn đúng công trình tương ứng. Hyperparameter search space được README chỉ tới Recbole/hyperchoice, best configuration tới cluster/bestparam.txt; cần đối chiếu chữ hoa/thường với root RecBole khi tải thực.

Chưa có lệnh cài đặt toàn bộ được thực hiện thành công trong phiên. Không đoán tên notebook hoặc chữ ký hàm của corrections mới. Để dùng code, tải repo đầy đủ bằng công cụ mạng khả dụng, pin commit, đọc license và kiểm tra environment trước.
